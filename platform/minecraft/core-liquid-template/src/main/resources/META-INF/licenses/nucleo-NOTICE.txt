This is a Java port with a bounded, literal codepoint fuzzy-matching contract,
not the upstream Nucleo frontend or concurrency engine. The algorithm, scoring,
normalization and case-folding tables derive from the pinned source above.
Unicode case folding is Nucleo's Unicode 15.0.0 table. Character classifications
were generated from Rust 1.99.1's Unicode 17.0.0 predicates and are frozen so
JDK updates do not change scores. See scripts/nucleo-parity/README.md in source
for settings, known upstream quirks, provenance and reproducible oracle checks.
