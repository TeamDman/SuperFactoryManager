# Isolated 1.19.2 production client bridge

This is a test-only, file-driven witness for an **unchanged** SFM production JAR. It is outside `platform/minecraft`, the source projection inputs and outputs, and the release build. It is not part of SFM. The runner uses cached Minecraft 1.19.2, Forge 43.4.0, LWJGL 3.3.1, assets, and JDK 17; it does not use Gradle or download anything. The launcher cache is read-only.

Call `Run-ReleaseClientBridge.ps1` with `-SfmJar`, `-ExpectedSha256`, `-PrismRoot`, `-JavaHome`, and a **new, separate** `-RunRoot`. Never pass a live game directory as the run root. The runner checks the cached launch graph before creating the run root, copies only the SFM JAR into that root, builds this tiny Forge bridge from source, starts one isolated client, and stops only the owned Java PID on timeout. It retains `launch.args`, stdout/stderr, game logs, and any result or screenshot. A missing bridge result must be classified from the log stage, not treated as an SFM failure. Forge itself may make a version-check request; the runner never downloads dependencies or artifacts.

The bridge waits for two rendered title-screen frames and captures an in-game screenshot through Minecraft's screenshot API, then exits. It does not enter a save or send user input. A title frame is a minimal visible-client startup smoke, **not** world render, GameTest, gameplay, or release-preset parity. The direct bootstrap classpath is reconstructed from Forge installer `version.json` plus cached launcher manifests; until a real pass it remains a launcher-harness hypothesis, not a claim about an ordinary Prism launch.

Status: the corrected hidden-window candidate attempt reached Forge/SFM client initialization but timed out without a rendered title frame. The original candidate JAR was unchanged; the official JAR has not been run through this bridge. The added event diagnostics compile but have not been exercised. Do not count this runner as a passing client-compatibility test until both production JARs render and produce comparable witnesses in separate scratch runs.
