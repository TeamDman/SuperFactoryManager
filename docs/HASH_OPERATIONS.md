# Hash-operation inventory

Scope: `platform/cli/sfm-propagate-changes`, completed N source and saved Windows measurements from 2026-10-19. Accepted O observations follow below; no total-time speedup is claimed. Source anchors below are crate-relative.

Counts/bytes are observed unless labelled static. **All timings are inclusive wall scopes, never isolated hash CPU.** Nested/parallel walls must not be added as command time or potential savings. Unknown work-count fields mean unavailable, not zero. “Unavailable” below covers unmeasured calls, bytes and cost. Exact-byte comparisons, membership and metadata identity checks are not content hashes.

`jar_build::ContentHash` is SHA-1 or BLAKE3 XOF **20 bytes**; snapshot BLAKE3 uses **32 bytes**. `ContentHash::from_path` reads a whole file; several admission helpers and the hash CLI stream.
