sfm-propagate-changes curseforge release now

Upload each release jar to `CurseForge` according to release-process rules

USAGE:
    sfm-propagate-changes curseforge release now [OPTIONS]

OPTIONS:
        --[no-]debug
            Enable debug logging, including backtraces on panics.
        --log-filter <STRING>
            Log level filter directive.
        --log-file <PATHBUF>
            Write structured ndjson logs to this file or directory. If a
            directory is provided, a filename will be generated there. If
            omitted, no JSON log file will be written.
        --stop-after <STRING>
            Request graceful cancellation after the named tracing/Tracy zone
            closes.
        --output-format <text,json,csv>
            Render typed command output as text, JSON, or CSV.
    -h, --[no-]help
            Show help message and exit.
        --[no-]html-help
            Open HTML help in the browser and exit.
    -V, --[no-]version
            Show version and exit.
        --completions <bash,zsh,fish>
            Generate shell completions.
        --export-jsonschemas <DIR>
            Export JSON Schema files for all config roots.
        --branch <STRING> [Required]
            Branch selector expression.
        --project <U64>
            CurseForge project ID (defaults to configured default project).
        --token <STRING>
            Explicit author API token; prefer --op-secret to avoid secrets in
            shell arguments.
        --op-secret <STRING>
            Explicit author token reference for this upload invocation.
        --[no-]dry-run
            Print planned uploads and metadata without uploading.
